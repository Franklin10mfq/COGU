# COGU Dev Library

Python library that takes a spacecraft trajectory problem defined with SymPy/CVXPY and generates standalone C code that solves it using the SCVx algorithm with ECOS. The output is a self-contained C executable with no Python dependency — intended for deployment on the COGU embedded unit.

---

## Requirements

### Python
- Python 3.10+
- `numpy`
- `sympy`
- `cvxpy`
- `cvxpygen`
- `scipy`

Install all at once:
```
pip install numpy sympy cvxpy cvxpygen scipy
```

### C build tools (Windows via MSYS2)
- **GCC** — install from [msys2.org](https://www.msys2.org), then run `pacman -S mingw-w64-ucrt-x86_64-gcc`
- **CMake** — `pacman -S mingw-w64-ucrt-x86_64-cmake`
- **Ninja** — `pacman -S mingw-w64-ucrt-x86_64-ninja`

Add MSYS2 to PATH before building:
```powershell
$env:PATH = "C:\msys64\ucrt64\bin;C:\msys64\usr\bin;" + $env:PATH
```

On Linux/macOS: install `gcc`, `cmake`, and `ninja` via your package manager.

## Quickstart — 3 steps

All commands run from the **repo root** (`COGU/`).

### Step 1 — Run the Python pipeline

Solves the Astrobee trajectory with SCVx and generates all C source files in `COGU_Dev_Library/astrobee_c_output/`:

```
python COGU_Dev_Library/verify_final.py
```

Expected output:
```
COGU pipeline -- Verificacion final
...
[Python] Convergio en X iteraciones
[Python] Posicion final: 5.0000  2.0000  1.6000
Archivos C generados en: COGU_Dev_Library/astrobee_c_output/
```

This generates:
- `astrobee_c_output/dynamics.c / .h` — spacecraft dynamics (SymPy → C)
- `astrobee_c_output/scvx_main.c` — full SCVx loop
- `astrobee_c_output/cpg_compat.h` — solver adapter
- `astrobee_c_output/CMakeLists.txt` — cross-platform build file
- `astrobee_c_output/solver/` — ECOS solver source (copied from `references/solver_t30/`)

### Step 2 — Compile with CMake

```powershell
cmake -S COGU_Dev_Library/astrobee_c_output `
      -B COGU_Dev_Library/astrobee_c_output/build `
      -G "Ninja" -DCMAKE_C_COMPILER=gcc

cmake --build COGU_Dev_Library/astrobee_c_output/build
```

### Step 3 — Run

```
.\COGU_Dev_Library\astrobee_c_output\build\cogu_scvx.exe
```

Expected output:
```
COGU convergio! Posicion final: 5.0000  2.0000  1.6000
```

## Project structure

```
COGU_Dev_Library/
├── sympy_cvx_converter/      # Library source (Python)
│   ├── pipeline.py           # Entry point: solve_trajectory()
│   ├── codegen.py            # SymPy → C code generation
│   ├── template_filler.py    # Fills scvx_main.c template
│   ├── problem.py            # CVXPY problem builder
│   ├── solver.py             # SCVx loop + RK4 discretization
│   └── templates/
│       └── scvx_loop_template.c
├── examples/
│   └── astrobee_simple.py    # Minimal usage example
├── references/
│   ├── astrobee_t30/         # Manual C loop (pre-pipeline reference)
│   ├── solver_t30/           # Pre-generated ECOS solver for T=30
│   └── test_cvxpygen_t30.py  # Script to regenerate solver_t30/ if needed
└── verify_final.py           # End-to-end verification (runs steps 1–3)
```

---

## Notes

- `references/solver_t30/` is committed to the repo to avoid re-running CVXPYgen (which can hit a `MemoryError` at T=30). Do not delete it.
- `astrobee_c_output/` is gitignored — it is fully regenerated by `verify_final.py`.
- For cross-compilation to ARM (COGU embedded target): pass `-DCMAKE_TOOLCHAIN_FILE=arm-none-eabi.cmake` to the first CMake command.
